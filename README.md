## 📊 Flipkart Sales Dashboard | Excel + Power BI

Excited to share my latest **Data Analytics Project – Flipkart Sales Dashboard** 🚀📈

I created this interactive dashboard using **Microsoft Excel & Power BI** to analyze sales performance and transform raw data into meaningful business insights.

📌 **Total Sales Price:** 4M+
📌 **Total Purchase Cost:** 424K+
📌 **Total Profit:** 4M+
📌 **Gender-wise Sales Analysis** 👨‍💼👩‍💼

📌 **Category & Product-wise Sales** 🛍️
📌 **Sales & Profit Trend Analysis** 📈
📌 **Electronics & Fashion Category Comparison**
📌 Interactive **Gender Filter/Slicer** for better analysis
